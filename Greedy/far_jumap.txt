**Problem Statement: Far Jump (Jump Game)**

**Description**
You are given an integer array `nums` where each element represents your maximum jump length at that position.

Initially, you are positioned at the first index ($0$) of the array. Determine if you are able to reach the last index.

---

**Input Format**

* A single line containing an integer array `nums` of size $N$.

---

**Constraints**

* $1 \le N \le 10^4$
* $0 \le nums[i] \le 10^5$

---

**Output Format**

* Return `true` if you can reach the last index, or `false` otherwise.

---

**Sample Input 1**

```text
nums = [2, 3, 1, 1, 4]

```

**Sample Output 1**

```text
true

```

**Explanation 1**
Jump 1 step from index 0 to 1, then jump 3 steps to the last index.

---

**Sample Input 2**

```text
nums = [3, 2, 1, 0, 4]

```

**Sample Output 2**

```text
false

```

**Explanation 2**
You will always arrive at index 3. Its maximum jump length is 0, which makes it impossible to reach the last index.
