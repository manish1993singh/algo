This code solves the classic **"Sum of Subarray Minimums"** problem (frequently found on platforms like LeetCode and HackerRank under variations like **"Subarray Minimums"** or **"Min Sum of All Subarrays"**).

It uses a **Monotonic Stack** to calculate the previous smaller element (`leftMin`) and next smaller element (`rightMin`) for each element, allowing it to compute the total contribution of each element as the minimum in $O(N)$ time. Note that in this specific Java implementation, modulo arithmetic is initialized (`long mod = (long) 1e9 + 7;`), but the result isn't explicitly taken modulo `1e9 + 7` during the sum summation loop (which is standard for variants requiring `% (10^9 + 7)`).

---

### Problem Statement

**Problem Title:** Sum of Subarray Minimums

**Description:**
Given an array of integers `arr`, find the sum of `min(b)`, where `b` ranges over every (contiguous) subarray of `arr`.

Since the answer may be large, return the answer modulo $10^9 + 7$.

---

**Input Format:**

* The first line contains an integer $n$, the number of elements in the array.
* The second line contains $n$ space-separated integers representing the elements of the array `arr`.

---

**Constraints:**

* $1 \le n \le 10^5$
* $1 \le arr[i] \le 3 \times 10^4$

---

**Output Format:**

* Print a single integer representing the sum of minimums of all possible contiguous subarrays modulo $10^9 + 7$.

---

### Sample Input

```text
4
3 1 2 4

```

### Sample Output

```text
17

```

### Explanation

The contiguous subarrays are:

* `[3]` $\rightarrow$ min is 3
* `[1]` $\rightarrow$ min is 1
* `[2]` $\rightarrow$ min is 2
* `[4]` $\rightarrow$ min is 4
* `[3, 1]` $\rightarrow$ min is 1
* `[1, 2]` $\rightarrow$ min is 1
* `[2, 4]` $\rightarrow$ min is 2
* `[3, 1, 2]` $\rightarrow$ min is 1
* `[1, 2, 4]` $\rightarrow$ min is 1
* `[3, 1, 2, 4]` $\rightarrow$ min is 1

Sum of minimums $= 3 + 1 + 2 + 4 + 1 + 1 + 2 + 1 + 1 + 1 = 17$.
